# cartas-cotemon

A tool to display custom images in a 3d pokemon tcg card model overlay for streaming.

[Open the dashboard](https://darodrian.github.io/cartas-cotemon/dashboard.html)

## How to use

1. Hit **Generar clave**.
2. Once it's generated, hit **Copiar URL de OBS**.
3. Paste the URL into OBS as a **Browser Source**.
4. Drag and drop your images into the dashboard, or use the file picker.
5. Select an image to make it active — the overlay will display it.
6. Change view options like rotation orientation and speed.
